# API 参考

以下接口仅用于文档展示，不提供真实服务。本次作业不要求开发后端，我用这组示例练习「如何把接口写清楚」，同时验证 MkDocs Material 对表格和 JSON 代码块的渲染是否正常。

## 查询文档列表

| 项目 | 内容 |
| --- | --- |
| 请求方法 | `GET` |
| 请求路径 | `/api/docs` |
| 功能 | 返回文档条目列表 |
| 认证 | 示例接口，不需要 |

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"},
    {"id": 2, "title": "API 参考"}
  ],
  "total": 2
}
```

## 查询单篇文档

- 请求方法：`GET`
- 请求路径：`/api/docs/{id}`
- 功能：按 id 返回单篇文档的标题与正文摘要。
- 路径参数：`id`，文档编号，对应上例 `items[].id`。

```bash
# 仅示意请求形式，本站是纯静态站点，并未提供该服务
curl https://example.invalid/api/docs/1
```

## 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `items` | array | 文档条目数组 |
| `items[].id` | number | 文档编号 |
| `items[].title` | string | 文档标题 |
| `total` | number | 返回的条目总数 |

## 状态码约定（示例）

| 状态码 | 含义 | 处理建议 |
| --- | --- | --- |
| `200` | 查询成功 | 解析 `items` 数组 |
| `404` | 编号不存在 | 检查路径参数 `id` |
| `429` | 请求过于频繁 | 稍后重试 |
